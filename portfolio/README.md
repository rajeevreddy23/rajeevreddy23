# Rajeev Reddy — Portfolio

A responsive, static portfolio website for Rajeev Reddy, AI Engineer and full-stack developer.

## Deploy to Netlify

- Import this GitHub repository in Netlify.
- Set **Base directory** to `portfolio`.
- Set **Publish directory** to `.` (relative to the base directory).
- No build command is required.

The site is plain HTML, CSS and JavaScript; no build step or environment variables are needed.

## Local preview

Open `index.html` in a browser or run a local static server from this folder.
